# Dependencies and attribution

Unity 6000.3.10f1; Universal RP 17.3.0; Input System 1.18.0; AI Navigation 2.0.10; Unity Test Framework 1.6.0. These are Unity packages under their shipped package licenses, available in each package's LICENSE.md in PackageCache. Existing starter-project dependencies have been retained. No paid Asset Store package is assumed.

All Rekindle source, scene composition, generated ground textures, geometric art, material colors, procedural motion, and synthesized chime samples were created for this project. No external art, music, or voice recordings were downloaded. Unity primitives, built-in fonts/shaders, terrain and navigation APIs are used under the installed Unity license. No third-party art attribution obligation has been introduced.

The unused starter dependency com.unity.ai.inference was removed. Rekindle uses no machine-learning runtime; the resolved Packages/manifest.json and packages-lock.json are authoritative.
