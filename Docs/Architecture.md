# Architecture

The scene's Session is a composition root and application-command coordinator. It binds explicit actor, presentation, interaction, and definition references. There is no global event bus. Owners commit state before raising local change events. Runtime state is not stored in ScriptableObjects.

- **Character** owns common health, energy, allegiance, death, revival, and temporary invulnerability for all actors. It does not reference input, AI, combat, or HUD.
- **Pool** owns spending, regeneration, bounds, and numeric restoration independently of Character. Energy is the slice's single authored ability resource.
- **Combatant / CombatRules** own attack commitments, energy cost, authoritative windup and recovery, hostility and range checks, and impact resolution. Player and enemy attacks use the same path. Animation events never apply damage. Definitions are Unity authoring assets.
- **PlayerInputSource / PlayerMotor / OrbitCamera** separate configurable Input System actions, acceleration/collision/evasion, and cursor-first orbit/steering/click detection. Camera sphere casts exclude the player's layer. Five pixels distinguishes a click from a drag.
- **EnemyBrain** composes perception, bounded approach, attack, recovery, leash, reset, and death with NavMeshAgent. Definitions distinguish melee, ranged, and boss attacks. The boss's every-third attack is a large delayed rupture. AttackTelegraph and ActorPresentation observe combat state.
- **Inventory** exclusively owns material, food, and identity-anchor stacks, capacity, swapping, atomic multi-item consumption, and validated snapshots. ItemDefinition carries stable ID, name, color, and description. Equipment owns the equipped weapon selection, derived from authoritative forge state.
- **WorldState** owns the four building stage records, depleted-node IDs, defeated-encounter IDs, final restoration facts, and the small objective sequence. Authored costs and gates are centralized here. This deliberately combines a small slice's restoration/dungeon/objective facts in one deterministic aggregate rather than introducing separate generic quest frameworks. Session coordinates rewards and commands; no presentation component mutates those collections.
- **WorldInteractable** requests gathering or restoration and observes before/stabilized/after scene groups. SoulPresentation derives wisp/spectre/restored appearance from its anchor building. WorldPhasePresentation derives corruption, regrowth, lighting, and settlement celebration from committed world facts.
- **GameHUD** queries authoritative state and issues application commands. It supplies menus, health/energy, target, six actions, context panel, inventory, objectives, and notifications using a consistent immediate-mode UI. This is a prototype UI rather than production UI Toolkit/uGUI authoring.
- **SaveStore** writes explicit versioned DTO snapshots to temporary files, atomically replaces an existing save, and keeps a backup. Read validates a candidate before applying it; malformed or unsupported candidates fall back to backup. Stable authored strings identify every persistent entity. Unity instance IDs and hierarchy order are never save identities.

The `Rekindle.Runtime` assembly contains game code; `Rekindle.Tests` is editor-only and references runtime. Editor authoring and validation remain in Editor folders, excluded from Windows builds. SliceBuilder builds a fixed handcrafted layout through Unity APIs, creates definitions and prefabs, paints terrain, bakes navigation, saves the production scene, and configures build scenes. Runtime does not generate the region.

Tradeoffs: progression content is authored in a compact aggregate rather than separate quest assets; weapon progression is a fixed earned capability; NPC activity is visual presence rather than schedules; presentation uses custom geometric models, procedural limb motion, generated chimes, and simple particles. The environment uses seeded decoration around a fixed route and handcrafted sanctuary, not a procedural dungeon. No multiplayer scaffolding or speculative class system exists.
